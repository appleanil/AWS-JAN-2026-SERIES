 # EC2 instance is created in an Availability Zone.
- Create a EC2 Instance and automatically created Root Volume also.
- An EBS volume is attached to the EC2 instance.
- An EBS snapshot can be created from the ESBS volume.
- Snapshots are stored by AWS in Amazon S3.
- A snapshot can be used to create a new EBS volume.
- So that we have Create a New EC2 Instance and also New Additional EBS Volume.
- From to attach new Additional EBS Volume.
